# FlowTab Privacy Policy

**Effective date:** June 22, 2026

FlowTab is a Chrome new-tab extension. It is designed to work locally on your device.

## Data stored locally

FlowTab saves the content and preferences you create in Chrome local storage on your device. This can include notes, todos, ideas, saved links, pinned Places, world-time cities, selected search engine, and background preferences. FlowTab uses this information only to provide its features. It does not send this information to the developer or to any analytics or advertising service.

You can remove stored FlowTab data at any time with **Settings → Reset local data**, or by removing the extension from Chrome.

## Network requests

FlowTab does not operate a backend or require an account.

When you explicitly run the `/fx` currency-conversion command, FlowTab requests the latest rate for the selected source currency from `https://open.er-api.com`. The request URL contains the source currency code only. Your notes, todos, ideas, saved links, Places, and settings are not sent with that request.

When you choose to search or open a site, FlowTab navigates Chrome to the search engine or website you selected. Those websites handle any data you provide to them under their own privacy policies.

## Data sharing and sale

FlowTab does not collect, sell, rent, share, or transfer personal data. It does not use advertising, analytics, tracking pixels, or affiliate tracking.

## Changes

If this policy changes materially, the updated policy will be published at the same public URL with a new effective date.
